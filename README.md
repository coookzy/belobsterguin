# Belobsterguin Research Institute Website

An early internet styled research website for the **Belobsterguin** (*Beluga penglobsterus arcticus*), a remarkable hybrid animal combining features of a white whale, lobster, and penguin.

## File Structure

```
belobsterguin/
├── images/
│   ├── belobsterguin.jpg    # Modern type specimen
│   ├── earliestbelob.png    # Historical photo (circa 1900s)
│   └── background.png       # Full-page background image
├── index.html               # Homepage
├── morphology.html          # Morphological description
├── habitat.html             # Habitat and behavior
├── gallery.html             # Photo gallery
├── research.html            # Research projects
├── contact.html             # Contact information
├── style.css                # Styling with background image
└── README.md                # This file
```

## Setup Instructions

Simply open `index.html` in any web browser to view the site. All images are organized in the `/images/` folder.

## Website Structure

- **index.html** - Main homepage with overview and quick facts
- **morphology.html** - Detailed morphological description with type specimen
- **habitat.html** - Habitat and behavior information
- **gallery.html** - Photo gallery with historical comparison
- **research.html** - Current research projects
- **contact.html** - Contact information and newsletter signup
- **style.css** - Classic early internet styling with full-page background
- **images/** - Folder containing all images including background

## Design Features

This website captures the aesthetic of early internet research sites (1990s-2000s):
- HTML 4.01 Transitional standard
- Table-based layout
- Classic color schemes (navy blue headers, simple backgrounds)
- Full-page background image (Arctic/underwater atmosphere)
- Basic navigation sidebar
- Retro typography (Times New Roman, Arial)
- Simple visitor counter aesthetic
- Authentic "blink" effect (for modern browsers)

## The Belobsterguin

The belobsterguin is a chimeric marine mammal with:
- Length: 3.5-4.5 meters
- Weight: 750-1,100 kg
- Massive lobster-like claws replacing pectoral flippers
- Penguin-style black/white countershading
- Beluga whale body structure
- Arctic coastal habitat

### The Three Virtues

The website explores how the belobsterguin embodies three fundamental survival virtues:
- **INTEGRITY** (White Whale Ancestry) → Social integrity and depth-tested wisdom
- **DISCIPLINE** (Lobster Morphology) → Biomechanical discipline and precise force application
- **RESILIENCE** (Penguin Lineage) → Extreme adaptive resilience in harsh conditions

This thematic framework is woven throughout all content, establishing memetic consistency.
